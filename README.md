# Aipotek: a playable instrument for a language model's inner workings

<p class="when">September 28, 2026</p>

Aipotek is an instrument for steering an open-weight language model's
internal state live, while it writes, from an ordinary MIDI controller. Knobs
and faders push the model's internal state along chosen directions word by
word, and the instrument makes its own sound from measured quantities: how
uncertain the model is, how surprised, and how hard the push is landing.
Every performance is recorded exactly, can be replayed word for word, and can
be rewound to any word to change one knob and hear what would have happened
instead. Every test runs against an untouched model and a meaningless decoy
push, and predictions are written down before runs.

The full release, with the open-source chassis (MPL-2.0), modules that can be
chained, and a demo, is coming in late October 2026.
